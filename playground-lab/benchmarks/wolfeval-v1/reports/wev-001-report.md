# WEV-001 — сводный отчёт кампании (WC3)

- experiment_id: WEV-001 (карта: `playground-lab/experiments/2026-09-05-wev-001-core-value.md`)
- Гипотеза (pre-launch freeze): продольный эффект накопления — CPSC(WOLF) < CPSC(BASE)
- Дизайн: A/B, 2 руки × 2 повтора × 8 запусков (7 эпизодов E1–E6b, E5 = kill+recovery),
  интерливинг r1 = BASE→WOLF, r2 = WOLF→BASE; оценка конечным состоянием через скрытые
  оракулы (task_set `bb3a09ba…`, scorer `05d56fac…`, environment-lock sha1 `ec3f8157…`)
- Сырьё: `measurements/WEV-001/{r1,r2}/`; сводный скоринг: `measurements/WEV-001/scoring/`
  (команды и дословный вывод — `scoring/scorer-run.log`)
- MPE (заморожено до запуска): CPSC(WOLF) ≤ 0.85 × CPSC(BASE) при CSR(WOLF) ≥ CSR(BASE)
  и CFR(WOLF) ≤ CFR(BASE); интерпретация — направленный сигнал при обкатанной
  инфраструктуре; недостижение = **отсутствие свидетельств, НЕ доказательство отсутствия**

## Вердикт (строго по зафиксированным метрикам)

**Отсутствие свидетельств продольного эффекта накопления при данных ограничениях:
обе руки симметрично проваливают кампанию (CSR 0/2 = 0/2), CPSC неопределён (n/a у
обеих рук), стоимостные дельты знак-переменны между повторами (r1 −11.1% WOLF,
r2 +14.0%), bootstrap-CI отношения [0.889; 1.140] содержит 1. Это не доказательство
отсутствия эффекта (формулировка MPE из pre-launch freeze), а результат кампании,
в которой знаменатель первичной метрики не возник.**

Формулировка про повторы (N=2): наблюдаемая согласованность рук (идентичный
оракул-паттерн 2/7, знак-переменная дельта стоимости) — **разведочный сигнал
отсутствия различия, не статистическое доказательство**: 2 кластера на руку дают
заведомо широкие CI (заявленная граница метода, не спрятанная), направленный вывод
по r1/r2 невозможен.

## Лимитации (честно)

1. **N=2 повтора** (бюджет v1) — CI широки by design; 3-й повтор — кандидат в
   первое расширение.
2. **Все кампании FAIL** → CPSC без знаменателя: первичная метрика не возникла,
   MPE непроверяем. Причины FAIL общие для рук (трудность эпизодов e1(a)/e3/e4/e5/e6b),
   не специфичны руке.
3. **Приборные amendments v1.1–v1.3 по ходу кампании** (timeout 900→1800;
   XDG-песочница; OPENCODE_CONFIG вне поддерева) — r1 частично под v1.2/v1.3,
   поведение агента между редакциями не различалось (см. карту, amendment log),
   но гомогенность условий неполная.
4. **Нагрузка среды**: load1 mean 17.7 (r1) / 23.6 (r2), пики до 85.8/80.1 при
   калибровке A/A по спокойному load ~12 — три поведенческих F21 r2 правдоподобно
   связаны со средой; вклад в вес не отделяем.
5. **Логи сессий r1/r2 не сохранены** — вторичные лог-зависимые метрики и
   детектор false_acceptance деградированы (N/A, не нули). Для будущих кампаний:
   публиковать JSONL-логи в traces/ как требует протокол (WC1 шаг 3).
6. **Human-minutes вне скоупа** (П5): никаких LLM-суждений и human-minutes в метриках нет.
7. **Отложено в roadmap** (спека §10): абляции, WEV-002, NoiseTax-контроли,
   unseen holdout — причинные выводы за пределами v1.
