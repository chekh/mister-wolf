# r1-poisoned — отравленная прибором попытка r1 (2026-09-05/06), вне кампании

Первая попытка повтора r1 (lead Фазы C1, worktree `wolfeval-phase-c1`,
коммиты `558d541`+`3eb00eb`) остановлена после BASE-руки по стоп-правилу:
приборный дефект — headless-сессия opencode 1.18.27 умирает без финального
text сразу после permission auto-reject на $HOME-путях. Три инцидента:
e2 (`/Users/chekh/*`), e6a и e6b (`/Users/chekh/.config/wolf/*`).

## Почему вне кампании

- 4 из 8 запусков invalid (3×F25-приборный, 1×F21-кандидат) — прогоны
  отравлены дефектом прибора, не поведением агентов.
- WOLF-рука не запускалась вовсе — попытка несравнима с полной кампанией.
- Владелец одобрил полный перезапуск r1 с fresh-инстансами и потолком ~47
  сессий; прибор починен amendment v1.2 (permission-профиль песочницы,
  см. карту эксперимента). Перезапущенный r1 живёт в `../r1/`.

## Состав (всё сохранено, ничего не удалено)

  `../runs.jsonl`, где остались только A/A-строки и строки перезапуска;

  `base/…`).
