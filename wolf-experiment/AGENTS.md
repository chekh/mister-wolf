# wolf-experiment — изолированный эксперимент: трёхуровневая схема агентов

Песочница для проверки иерархии **Wolf (координатор) → Executor (менеджер
задачи) → Workers (исполнители)**. Проект временный, без git.

Язык всех артефактов и ответов — русский.

## Каталоги

- `coordinator/` — Task Brief'ы Wolf'а (и ничего больше);
- `executor/` — Report'ы Executor'а;
- `workers/` — код, созданный воркерами;
- `logs/` — журналы (заполняется в фазе 2).

## Правила эксперимента

- Обмен между уровнями — только файлами (brief / report / код), не пересказом.
- Wolf не пишет код и не запускает команды; executor не пишет код сам — только
  через воркеров; воркеры не спавнят агентов (у них нет тула task).
- Не выходить за пределы каталога `wolf-experiment/`.
