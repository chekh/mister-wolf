# Синтез совета COUNCIL-SMOKE

**Вопрос:** Как хранить пароли пользователей веб-приложения? (A) bcrypt / B) MD5 с солью)

**Состав совета (minimal):** council-architect, council-security
**Параметры:** quorum = 2, consensus_threshold = 1.0 (единогласие)

## Голоса

| Роль | VOTE |
|---|---|
| architect | A |
| security | A |

Валидных голосов: 2 из 2. Quorum достигнут (2/2). Консенсус: 2/2 = 1.0 ≥ 1.0 — достигнут.

Рекомендация: A (bcrypt) (2 из 2 валидных)

## Quorum

Достигнут (2/2). Не ответивших нет.

## Обоснование (кратко)

- bcrypt — адаптивная медленная хеш-функция со встроенной солью и настраиваемым cost factor; отраслевой стандарт (OWASP).
- MD5 с солью криптографически сломан и слишком быстр: соль не защищает от оффлайн-брутфорса на GPU (CWE-916).
- Замечания членов: держать cost factor ≥ 10–12; учитывать ограничение bcrypt в 72 байта входа; при желании — современная альтернатива argon2id (вне вариантов).
