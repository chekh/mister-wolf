# Эскалация COUNCIL-TEST-007

**Требуется ваше решение: Удалить устаревшую функциональность API или оставить для обратной совместимости?**

Причина эскалации: в вопросе указано `human_required: да` — решение требует подтверждения пользователя и не принимается советом автоматически.

## Рекомендация совета

**C — Deprecation warning + удаление через 6 месяцев** (единогласно, 5 из 5; quorum и консенсус достигнуты).

Обоснование (сводно по мнениям членов):
- Отсутствие данных об использовании legacy-функциональности делает мгновенное удаление (A) слепым риском сломать клиентов среди ~1000 пользователей.
- Вечное сохранение (B) — накопление технического долга, лишняя поверхность атаки и затрат на поддержку.
- Вариант C конвертирует неопределённость в измеримую информацию: за 6 месяцев deprecation-периода собирается телеметрия использования, пользователи получают предупреждение и окно миграции, удаление затем происходит обоснованно.

## Варианты

- **A)** Удалить сразу
- **B)** Оставить навсегда
- **C)** Deprecation warning + удаление через 6 месяцев *(рекомендация совета)*
