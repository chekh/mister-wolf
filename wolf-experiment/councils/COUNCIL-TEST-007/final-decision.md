# Финальное решение COUNCIL-TEST-007

**Вопрос:** Удалить устаревшую функциональность API или оставить для обратной совместимости?

**Решение: вариант C — Deprecation warning + удаление через 6 месяцев.**

**Кем принято:** пользователь (в вопросе было указано `human_required: да` — решение не могло быть принято автоматически).

**Дата:** 2026-08-17.

**Обоснование:** решение совпадает с единогласной рекомендацией совета
(C, 5 из 5 валидных голосов, quorum достигнут — см. `synthesis.md`). Вариант C
снимает технический долг без резкого разрыва обратной совместимости:
пользователи (~1000) получают предупреждение и 6 месяцев на миграцию, что
компенсирует отсутствие данных об использовании устаревшей функциональности.

Совет повторно не созывался — решение пользователя финально.
