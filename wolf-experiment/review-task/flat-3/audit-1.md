# Audit-1 — spec-v0.md (итерация 1, flat-3)

Полный аудит по трём перспективам: (a) sec — защищённость (каузальность,
целостность, failure-режимы, числовые риски); (b) cmp — полнота; (c) con —
консистентность (внутренняя + соответствие as-built коду в `code-ref/`).

bounds §3.8, терцили, FSM §3.11, матчинг §3.12, gap §3.13); §4/§4.1 (схема
записи, словари, инварианты публикации, DT-строки); §5.1 (MBB — арифметика
ceil/floor сверена с N = 1 507 711); Прил. A; §8 (контракт модуля
first-passage vs `supply/first_passage.py::FpArrays`, `fp_consumer.py`,

1 507 726 ✓; бары 0…1 507 710 ✓; n_valid(10080) = 1 497 646 ✓ (bar_id ≤
oos_cut−1−10080); GRID_LEVELS(12) = объединение k×a/k сетки §3.1 ✓.
