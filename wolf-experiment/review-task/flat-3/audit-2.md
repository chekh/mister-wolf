# Audit-2 — spec-v1.md (итерация 2, flat-3)

Полный аудит по трём перспективам с акцентом второго прохода: publication-слой
(кодировка бутстреп-выходов, манифест прогона, гейт потребления артефакта),
сверка nullability/имён полей и календарных конвенций с as-built, точность
состояний матчинга. Перепроверены также правки итерации 1 (противоречий не
внесли: §3.4↔§8 согласованы; §10.3 ↔ §3.13 ссылка корректна; числа §5.1
согласованы с §5.5 «≈ 37 nonoverlap-equivalent»).
