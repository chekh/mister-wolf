# Audit-1 — spec-v0.md (итерация 1)

Дата: 2026-08-17. Метод: полный аудит по трём перспективам — sec
(защищённость), cmp (полнота), con (консистентность), со сверкой as-built
кода `code-ref/` (supply/: first_passage, fp_consumer, delay, touch_groups,
episodes, matching, wp2_cells, catalog).

| F1-01 | major | sec | §3.6 | Знаменатель метрик задержки — «успешные якори (0 < t_hit ≤ h) с валидным delayed_row»; валидность исходного якоря для h (window_len(t) ≥ h, маска V_h §3.2) не требуется. Усечённые якори (window_len < h) с t_hit ≤ window_len < h молча проходят маску `t_hit ≤ h` и попадают в знаменатель — систематическое смещение долей (у правого края hit-rate ниже).
