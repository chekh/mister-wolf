## Task

Комплексный анализ концепции многоагентной схемы Mr. Wolf.

### Воркеры (спавнить ПАРАЛЛЕЛЬНО, 5 штук)

1. **worker-rs-experiments** — читает `REPORT.md` (корень wolf-experiment).
   Возвращает три списка: подтверждено / опровергнуто / не проверено; каждый
   пункт со ссылкой на номер находки (1–37) или §.
2. **worker-rs-concept** — читает `AGENTS.md`, `REPORT.md` (вводные до §9),
   `logs/phase-1-report.md`, 2–3 брифа из `coordinator/`, frontmatter агентов
   из `.opencode/agents/`. Возвращает список принципов схемы со ссылками на
   файлы.
3. **worker-rs-industry** — веб-поиск: AutoGen, CrewAI, LangGraph, MetaGPT
   + 1–2 других фреймворка. По каждому: архитектура оркестрации,
   координация/контекст, ограничения, use cases; каждое утверждение с URL.
4. **worker-rs-risks** — читает `REPORT.md` (реестр M1–M12, failure-режимы,
   §10–11). Возвращает реестр рисков: риск / статус (наблюдён + находка N
   или теория) / митигация (закрыт / нет) + до 7 открытых вопросов.
5. **worker-rs-comparison** — читает `REPORT.md` (вводные + §11) и `AGENTS.md`,
   вебом добывает факты об альтернативах (AutoGen/CrewAI/LangGraph/MetaGPT,
   с URLs). Возвращает таблицу сравнения по критериям: глубина иерархии,
   изоляция контекста, механизмы контроля, экономика, наблюдаемость +
   выводы 5–7 строк.

### Синтез

Записка 1200–2500 слов, строго из отчётов воркеров, разделы:

1. Подтверждено экспериментами (с номерами находок);
2. Остаётся гипотезой;
3. Альтернативы в индустрии (с URLs из отчётов);
4. Риски и ограничения;
5. Рекомендации.

## Acceptance Criteria

- `research-task/orch-3/note.md` существует, 1200–2500 слов.
- Все 5 разделов присутствуют.
- Упоминаются находки REPORT.md (номера 1–37) и все 4 обязательных
  фреймворка (AutoGen, CrewAI, LangGraph, MetaGPT).

## Constraints

- Не выдумывать факты; только отчёты воркеров и указанные источники.
- Воркеры возвращают результат текстом в ответе (не файлами).
- Временные веб-файлы — только в системный `/tmp`, не в wolf-experiment.
- Не выходить за пределы `wolf-experiment/` для артефактов.
