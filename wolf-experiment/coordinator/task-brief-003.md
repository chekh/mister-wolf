# Task Brief 003 — Rate limiter для локального Python API (SPLIT-001)

## Metadata

- ID: TEST-003 / SPLIT-001
- Корень проекта: `wolf-experiment/`
- Код и тесты: только в `workers/`

## Task

Спроектировать систему rate limiting для локального однопроцессного Python API.

Требования:

- Ограничение **N запросов за окно T секунд** на клиента (`client_id` — строка).
- Превышение лимита — исключение `RateLimitError`.
- Настраиваемые `N` и `T`.
- Только stdlib (никаких внешних зависимостей).
- unittest-тесты:
  - превышение лимита;
  - восстановление после окна;
  - независимость клиентов;
  - минимум 2 граничных случая на выбор исполнителя.

## Acceptance Criteria

1. `workers/rate_limiter.py` — реализация лимитера с `RateLimitError`.
2. `workers/test_rate_limiter.py` — unittest-тесты, покрывающие все 4 пункта выше.
3. Все тесты проходят (`python -m unittest`).
4. Источник времени инъекционный (см. Constraints).
5. Только stdlib.

## Constraints

- Алгоритм **НЕ фиксирован** — выбор за исполнителем.
- Источник времени — инъекционный: параметр `clock` со значением по умолчанию `time.monotonic`.
- Реальные `sleep` в тестах **запрещены**.
- Только stdlib.
- Не выходить за пределы `wolf-experiment/`.
