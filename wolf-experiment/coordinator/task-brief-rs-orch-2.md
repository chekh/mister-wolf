## Task

Комплексный анализ концепции многоагентной схемы Mr. Wolf. Исполнитель —
`executor-researcher`: он руководит 5 воркерами (спавнит их ПАРАЛЛЕЛЬНО),
затем синтезирует аналитическую записку `research-task/orch-2/note.md`
строго из отчётов воркеров.

### Воркеры (параллельно)

1. **worker-rs-experiments** — читает `REPORT.md` (корень wolf-experiment).
   Возвращает три списка: «подтверждено» / «опровергнуто» / «не проверено»;
   каждый пункт со ссылкой на номер находки (1–37) или §.
2. **worker-rs-concept** — читает `AGENTS.md`, `REPORT.md` (вводные до §9),
   `logs/phase-1-report.md`, 2–3 брифа из `coordinator/`, frontmatter агентов
   из `.opencode/agents/`. Возвращает список принципов схемы со ссылками на
   файлы.
3. **worker-rs-industry** — веб-поиск: AutoGen, CrewAI, LangGraph, MetaGPT
   + 1–2 других фреймворка. По каждому: архитектура оркестрации,
   координация/контекст, ограничения, use cases; каждое утверждение с URL.
4. **worker-rs-risks** — читает `REPORT.md` (реестр M1–M12, failure-режимы,
   §10–11). Возвращает реестр рисков: риск / статус (наблюдён + находка N
   или теория) / митигация (закрыт/нет) + до 7 открытых вопросов.
5. **worker-rs-comparison** — читает `REPORT.md` (вводные + §11) и
   `AGENTS.md`; вебом добывает факты об альтернативах
   (AutoGen/CrewAI/LangGraph/MetaGPT, с URLs). Возвращает таблицу сравнения
   по критериям: глубина иерархии, изоляция контекста, механизмы контроля,
   экономика, наблюдаемость + выводы 5–7 строк.

### Записка (`research-task/orch-2/note.md`, 1200–2500 слов)

Синтез строго из отчётов воркеров, разделы:

1. Подтверждено экспериментами (с номерами находок);
2. Остаётся гипотезой;
3. Альтернативы в индустрии (с URLs из отчётов);
4. Риски и ограничения;
5. Рекомендации.

Не выдумывать факты: всё — только из отчётов воркеров.
