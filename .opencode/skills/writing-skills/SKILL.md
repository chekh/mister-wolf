# writing-skills: создание и правка скиллов Wolf

## Обзор

Скилл Wolf = промпт-методология в `templates/base/skills/<имя>/SKILL.md`; в
проекты-пользователи попадает рендером (штампы, `wolf init`/`wolf sync`).
Правка живого скилла ведётся в шаблоне, не в отрендеренной копии.

## Жизненный цикл

1. Новый скилл: папка `templates/base/skills/<имя>/SKILL.md` с front-matter
   `name` + `description` (описание — триггер загрузки: когда применять).
2. Тело: обзор → вход/выход → процесс (шаги) → железные запреты.
3. **Таблица трассировки адаптации обязательна** для каждого адаптированного
   скилла: источник → судьба пункта (сохранено/заменено/выброшено/добавлено) → почему.
4. Правка существующего: шаблон → `wolf sync` → guard-тесты соответствующего набора.
5. Граница с intake: скиллы базового набора — здесь; внешние скиллы мира —
   через wolf-skill-intake (гейт владельца), не через этот скилл.

## Запреты

- Править `.opencode/skills/<имя>/SKILL.md` напрямую (перезатрётся sync).
- Создавать скилл без таблицы трассировки (для адаптаций) или без описания
  триггера (для новых).
- Дублировать существующий скилл набора — сначала `wolf search`.
