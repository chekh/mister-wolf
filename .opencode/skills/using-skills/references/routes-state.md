# Сохранение, Git и передача

| Когда | Как применить | Результат |
| --- | --- | --- |
| Git-граница: вход, checkpoint, завершение | wolf-git: проверить baseline, сохранность и полномочия | Подтверждённое состояние Git |
| Нужна изоляция записи | using-git-worktrees: назначить владельца и отдельное место | Рабочая копия по политике |
| Смена сеанса/исполнителя или восстановление | wolf-handoff: передать состояние и решения адресно | Продолжение без повторной работы |
| Готовы интеграция и уборка | finishing-a-development-branch: проверить сохранность и доступные действия | Разрешённое завершение |
| Выбирается режим/место документа | [Правила проекта](project-rules.md): использовать существующее соглашение | FULL/LITE/FIX и правильные материалы |
| Создан полезный скрипт | [Инструменты проекта](project-tools.md): сохранить и учесть карточкой | Средство для следующих задач |

Рабочая память — по [адресному контракту](context-and-memory.md). Принятое на
применимой revision не повторяется; незавершённое продолжается, устаревшее
evidence проверяется адресно. Недоступное не превращай в «успешно». Грязная
рабочая копия не чистится ради удобства; сначала сохраняется нужный результат.
