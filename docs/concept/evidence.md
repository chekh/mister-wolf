## E1 — протокол (зафиксирован ДО эксперимента)

**Цель:** количественное сравнение Wolf с одиночным агентом + ablation — доказать, что качество возникает из архитектуры, а не из большего числа вызовов моделей.

Обязательные пункты протокола:

- одинаковые модели и бюджеты (токены, время, число вызовов) во всех руках;
- одинаковые task sets; случайное распределение задач по рукам;
- критерии успеха и правила остановки зафиксированы ДО эксперимента;
- учёт стоимости токенов и времени;
- учёт влияния human intervention (фиксировать каждое вмешательство);
- model/version pinning + полный provenance (какая модель, версия, конфиг, seed данных).

Ablation-оси:

1. single agent vs L0/L1/L2;
2. иерархия без типизированной памяти vs с типизированной памятью;
3. без консилиума vs с консилиумом;
4. без Стюарда vs со Стюардом.

**Статус:** запланирован (Фаза E roadmap-v3); 30–100 задач.

Протокол фиксирован до запуска; изменения протокола после старта — только отдельным решением владельца с указанием причины.
