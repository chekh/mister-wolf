# Wolf: смысловое покрытие канона

**Дата:** 2026-08-31 · **Канон:** [concept.md](concept.md) v3.3

Контроль исполнения анти-регрессионного принципа: концепция не теряет значимые
тезисы без явного решения. Текст может сжиматься и реструктурироваться —
смысловое покрытие отслеживается этой таблицей. Тезис нельзя удалить молча:
только `superseded` (с указанием замены) или исключение явным решением владельца.

Статусы: **active** — тезис в каноне; **draft** — принят, реализация/контракт
впереди (зрелость — [maturity.md](maturity.md)); **superseded** — заменён
(замена указана в примечании).

## Правило обновления

Ревизия концепции обновляет эту таблицу в том же коммите: новые тезисы —
`active`/`draft`; убранные — `superseded` со ссылкой на замену; исключение —
только решением владельца с записью в Историю версий концепта.
