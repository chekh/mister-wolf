# Wolf: смысловое покрытие канона

**Дата:** 2026-11-10 · **Канон:** [concept.md](concept.md) v3.4.0

Контроль исполнения анти-регрессионного принципа: концепция не теряет значимые
тезисы без явного решения. Текст может сжиматься и реструктурироваться —
смысловое покрытие отслеживается этой таблицей. Тезис нельзя удалить молча:
только `superseded` (с указанием замены) или исключение явным решением владельца.

**Стабильные идентификаторы.** Редакторское уточнение формулировки не меняет
`claim_id` и не считается удалением тезиса. Префиксы: `ORG-` — организация
(L0/L1/Council/роли), `MEM-` — память/канон, `GOV-` — мутация/активация/
Стюард/governance, `SEC-` — security/trust, `EVD-` — доказательства/честность
формулировок, `PIL-` — опоры ценности/позиционирование, `BND-` — границы продукта.

Статусы — нормативные, только четыре:

- **active** — действующий канонический тезис;
- **proposed** — кандидат в канон;
- **superseded** — заменён (замена указана в примечании);
- **rejected** — явно отклонён.

Зрелость реализации живёт исключительно в [maturity.md](maturity.md) и не влияет
на статус: тезис может быть `active` (нормативно объявлен в каноне) при любой
зрелости реализации. На 2026-08-31 строки `proposed`/`rejected` отсутствуют.

## Правило обновления

- Ревизия концепции обновляет эту таблицу **тем же коммитом**, что и [concept.md](concept.md).
- Статусы — только `active` / `proposed` / `superseded` / `rejected`; зрелость
  реализации живёт исключительно в [maturity.md](maturity.md) и статусом тезиса
  не является.
- Редакторское уточнение формулировки не меняет `claim_id` и не удаляет тезис.
- Убранный тезис — `superseded` со ссылкой на замену в примечании; явно
  отклонённый — `rejected` с указанием решения.
- Исключение тезиса без замены — только явным решением владельца с записью
  в Историю версий концепта.
