## Фаза D · Контур самообучения Ф20–26 (~5–8 сессий)

Промышленная версия обработки знаний (концепт §5.1). Порядок фиксирован спекой:
Ф20 сигнальный лог → Ф21 паттерны (кластеризация по ключу) → Ф22 Стюард полный (пост-аудит, Analyzer-Worker, Sandbox Replay, complain) → Ф23 STOP-гейт + read-only зоны → Ф24 GEPA → Ф25 AFlow → Ф26 decay по пробегу.

**+ Новое (решение владельца 2026-08-29): Архивариус калибрует роутер** — агрегат «модель × тип задачи × вердикт × weighted-цена» по сигнальному логу → правки routing-объектов через конвейер активации. Роутер самонастраивается на фактах проекта.

Чекпоинты: E2E после каждой фазы; пороги автономии B→B+→C (30/60/90 сессий [ВА]); возврат B+→B при ≥30% отмен.
