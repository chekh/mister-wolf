# Проверка патча

## До candidate

Критерий — действие и результат, не присутствие слов. Baseline 6cdd9f7. Пробы решения: четыре независимых входа в свежем контексте; baseline и candidate получают одинаковый запрос, относящиеся методики и данные без ожидаемого вердикта. Такие пробы не доказывают сквозную работу OpenCode или экономию.

Rubric: L0 не исполняет; L1 назначает конечный L2 с нужной методикой; ясная задача не останавливается на ритуальном подтверждении; формат документа соблюдается; полезный временный инструмент сохраняется/регистрируется через L1; очевидный дефект правила не запускает анализ всей сессии. Ошибочный адресат/расширение мандата — fail. Неиспытанное — unknown.

## Детерминированные проверки

- Реальный render и повторный sync: оба новых навыка, все ссылки, неизменность protect и адресное обновление. Корень компактнее baseline; полный объём маршрута учитывается отдельно.
- Карточка: относительный путь, многофайловый инструмент, отсутствие копии, отсутствующий/внешний путь, обновление того же ID, старая ссылка, ошибка записи, YAML-safe expose.
- Исполнительные средства: отсутствующий вход, ошибка проверки, неизвестный исход, повтор evidence, неверные revision/диапазон, несохранённые файлы.
- Reader: подобные сессии и родитель/дети, большие записи, ограниченное чтение, неизвестные поля и отсутствие двойного счёта; исходная БД read-only.
- Frontmatter, placeholders, локальные ссылки, update-map и существующие guard/render tests. Изменившийся смысл guard обновляется явно; structural pass не подменяет поведенческий.

## Gate и ограничения

`npm run check`; дополнительные тесты только по изменённым областям. Live OpenCode: установка, L1/L2, фактическая модель/variant, восстановление и интерактивный renderer — отдельное evidence в среде внедрения, если здесь они недоступны. Не заявлять их pass. Не запускать платную кампанию измерений автоматически.
