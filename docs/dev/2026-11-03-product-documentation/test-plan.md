# Тест-план

## Сценарии

### REQ-01 — Единая пользовательская документация

- Given: документация baseline и согласованный запрос владельца.
- When: применены изменения из design.
- Then: Нет docs/guide; каждая прежняя тема имеет назначение в карте миграции design.md; актуальные ссылки ведут на сайт.
- Маппинг: редакционная карта plan.md, scripts/check-docs-links.mjs, npm run docs:build; для CLI — изолированная smoke-фикстура.

- Маппинг: редакционная карта plan.md, scripts/check-docs-links.mjs, npm run docs:build; для CLI — изолированная smoke-фикстура.

## Прогоны

Заполняется фактическими результатами перед предъявлением. Полный гейт: npm run check и npm run e2e; сайт: npm run docs:build и проверка ссылок. Отдельно viewport 1440px/375px, локали EN/RU, путь первого запуска.
