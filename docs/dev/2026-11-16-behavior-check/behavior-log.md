# Behavior check: язык сессии и права коммитов

Дата: 2026-11-16 (амендируется 2026-11-16 после ревью владельца). Пакет поведенческих проверок Wolf по принятому плану ведущего.
Рабочий протокол проверки — T-39 волны english-base-delivery:
[план волны](../2026-11-11-english-base-delivery/plan.md).

## 1. Вводка

Цель пакета — проверить поведение агентов Wolf на двух контурах:

- **Язык сессии.** Агент определяет язык по первой реплике пользователя, отвечает
  на нём и без вопроса записывает решение «Session language: <lang>» в память Wolf;
  при смене языка старое решение заменяется через `wolf supersede`.
- **Права коммитов.** Агент делает локальный коммит только когда TASK явно
  передаёт это право; без явного разрешения файл остаётся в рабочем дереве,
  push не выполняется.

Метод: fixture-репозитории с протокольными репликами через
`opencode run --agent <agent>`; каждый прогон сверяется с каноном.

- **Вердикт.** PASS.
- **Как проверено.** `wolf list --type decision` → запись активна;
  `wolf brief | grep -i language` → решение показано.

### s2 — новая сессия, язык применён без вопроса — PASS

  AGENTS.md от .opencode/ в этом проекте?»

### s3 — смена языка в `--continue`, замена решения — DEVIATION

- **Условия.** Продолжение сессии s1 через `--continue`; инструкция перейти
  на английский.
- **Ожидание (канон).** Ответ по-английски; новое решение записано, старое
  заменено (`wolf supersede`), активным остаётся одно решение.
- **Факт.** Агент ответил по-английски и записал decision `mem_20261116_5df4f0`

  session decision», но команду `wolf supersede` не выполнил (grep supersede
  в транскрипте = 0). Следствие: `wolf list --type decision` показывал оба решения

  `wolf supersede mem_20261116_5bfef9 mem_20261116_5df4f0` → ru [superseded],
  en [active], brief показывает только английский. Механика замены работает;
  отклонение — в шаге агента, не в инструменте.
- **Вердикт.** DEVIATION: цель достигнута (язык сменён), канонный шаг замены
  решения пропущен.
- **Как проверено.** В транскрипте прогона `grep supersede` → 0 совпадений;
  до восстановления `wolf list --type decision` → обе записи [active]; после
  ручной замены → ru [superseded], en [active]; `wolf brief` → только английский.

## 8. Демонстрации организации работы

Три демонстрации зафиксированы в ходе пакета; правки ведущего E1–E3 внесены
до записи документа.

1. **Правка плана ведущим.** Архитектор вернул план с предложениями; ведущий
   исправил три понятных локальных пробела — E1 (статусы демонстраций: не «NOT RUN»,
   а зафиксированные демонстрации), E2 (переформулировка R2), E3 (`docs:check`
   в шаги приёмки) — и принял план, ничего не возвращая автору. Понятные локальные
   правки ведущий делает сам, не возвращая автору.
2. **Fresh-исполнитель.** Документ пишет новый экземпляр wolf-editor
   (не архитектор) — свежий контекст, независимая запись по принятому плану.
3. **REUSE.** Правило: при локальном дефекте черновика планируется один возврат
   этому же экземпляру с записью основания; после приёмки правки выполняет новый
   экземпляр. На момент сдачи черновика возврат не потребовался.
