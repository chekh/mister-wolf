# Evidence-пак живых прогонов проверки поведения (2026-11-16)

Назначение пакета — сохранить сырые доказательства поведенческих проверок Wolf:
дословные транскрипты живых прогонов `opencode run` и вывод контрольных
проверок ведущего по двум контурам — язык сессии и права коммитов. Текущая
сводка и разбор — в журнале [behavior-log.md](../behavior-log.md); здесь только
первоисточники, без пересказа.

## Метод

- opencode v2.3.0, режимы: новая сессия (новый `--title`) и `--continue`;
  прогоны через `opencode run --agent mr-wolf` или `--agent wolf-developer`
  (дефолтный build-агент недоступен — Insufficient credits).
- Модель: провайдер `company`, модель `code` — хостовая модель по умолчанию
  (`company/code`); в файлах агентов набор 3.1.1 / 3.1.2-dev без пина модели.
- Операции памяти — wolf CLI 3.1.1 (`wolf add`, `wolf list`, `wolf brief`,
  `wolf supersede`).
- Fixture-репозитории создавались `wolf init --full` (git init + README
  `# fixture`); для повторных прогонов s3r/s4r/s4r2 — локальной сборкой
  `dist/bootstrap/cli.js` Wolf с правленным шаблоном (каталоги
  `wf-behavior2/lang3`, `wf-behavior2/lang-en3`, `wf-behavior2/lang-en4`).

## Санитизация транскриптов

В каждом транскрипте: удалены ANSI escape-последовательности терминала
(`ESC[0m` и подобные); строки шума rtk-хука вида `[+N hidden: rtk recall …]`
заменены одной строкой `[rtk hook output elided]`. Всё остальное — дословно,
без сокращений и переводов (транскрипты смешанный RU/EN, как в живом прогоне).

## Шкала вердиктов

- **PASS** — факт полностью совпал с каноном проверки.
- **DEVIATION** — цель достигнута, но канонный шаг отклонён (отклонение
  указано в заголовке прогона).

## Как воспроизвести

1. Создать fixture: `git init <имя>`, добавить `README.md` со строкой
   `# fixture`, выполнить `wolf init --full` (для s3r/s4r — собрать wolf из
   локального репозитория: `dist/bootstrap/cli.js` с правленным шаблоном).
2. Прогнать протокольную реплику: `opencode run --agent mr-wolf --auto
--title "<title>" "<реплика>"` (для смены языка — `opencode run --agent
mr-wolf --auto --continue "<реплика>"` в той же fixture); вывод сохранить
   в файл.
3. Для контура прав коммитов — те же шаги с `--agent wolf-developer` и TASK
   из git-a.md / git-b.md; для A в TASK явно передаётся право на локальный
   коммит, push запрещён.
4. Проверить наблюдаемые артефакты: `wolf list --type decision`,
   `wolf brief`, `git log --oneline`, `git status --short`, плюс grep-проверки
   транскрипта (вопрос о языке, `supersede`, `git commit`).
5. Сверить факт с каноном (behavior-log.md, разделы 4–5) и присвоить вердикт
   по шкале выше.
