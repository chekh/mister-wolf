### Находки раунда 2 (независимый ревьюер)

SUMMARY: 1 critical / 4 major / 3 minor — VERDICT: CHANGES_REQUIRED

- F-1 (critical, REQ-07): гвард breakglass «WOLF_SESSION не задан» нежизнеспособен —
  `ensureCliSessionId` (`cli-entry.ts:488`, `actor.ts:27`) выставляет
  `WOLF_SESSION='cli-<uuid>'` в каждом CLI-процессе; терминал всегда «в сессии».
- F-2 (major, REQ-05 AC2): «инъекция идемпотентна за сессию» не опирается на код:
  гвард INJECT_HEADER — на system-текст, TTL-кэш — на процесс; после TTL активная
  сессия может получить новую версию.
- F-3 (major, REQ-03 AC1): событие отказа guard не спроектировано, хотя карта
  покрытия его обещает (закрытый enum событий).
- F-4 (major, REQ-06 AC2/конкурентность): атомарность «в той же lock-транзакции»
  несовместима с нереентерабельным FsMemoryLock (прецедент-ловушка
  `tool-librarian.ts:167`).
- F-5 (major, REQ-08 AC2): facet-guard `add-memory-object.ts:96` бросает
  «facet is only valid for type note» до schema-builder — proposal на не-note
  типах заблокирован; путь записи saveProposal не определён.
- F-6 (minor, REQ-02 AC2): миграция при отсутствии активного head (только
  superseded-цепочка) не определена.
- F-7 (minor): `isPlaybookNote` (`scaffold-agent.ts:28`) не распознаёт face —
  `scaffold --from-playbook <face-id>` сломается после миграции.
- F-8 (minor, REQ-03): MCP-поверхность face/propose не рассмотрена.

Сошлось (протокол ревьюера): покрытие REQ/NFR построчно без искажений; факты
кода (словарь 7→8, alias, enum событий, FieldSpec, T18, router-гвард, все
ссылки на строки) точны; security-свойства (спуфинг-риски, пиннинг автора,
миграция без потерь) подтверждены.

### Ответы автора (L1) и исправления

- F-1 — принято (верифицировано по `actor.ts:27`, `cli-entry.ts:488`). Гвард
  заменён на префиксный: `opc-*` → отказ (opencode-процесс агента), `cli-*`/
  отсутствие → терминал владельца. Правка: §Guard, псевдокод.
- F-2 — принято с уточнением (см. ниже): механика переописана через гвард
  INJECT_HEADER в system чата + допущение персистентности + e2e-проверка в
  test-plan; остаточный случай №2 (пересборка system рантаймом) признан и
  вынесен владельцу (конфликт REQ-05 AC2 ↔ NFR-01 — правка плагина ломает
  ожидания TTL-теста `wolf-router-plugin.test.ts:218`, проверено по коду теста).
  Правка: §Отказы, ADR-4, карта REQ-05, «Решения для визы» п.4.
- F-3 — принято: добавлено событие `memory.face.denied` (схемная правка п.4,
  псевдокод, карта REQ-03).
- F-4 — принято (верифицирован прецедент tool-librarian): внешний lock в
  createFaceVersion, вложенные вызовы с `lock: undefined`. Правка: псевдокод,
  §Отказы.
- F-5 — принято: в сводку добавлено расширение facet-guard в add-memory-object;
  путь записи saveProposal определён (через addMemoryObject — валидация,
  memory.added, индексация).
- F-6 — принято: явный skip с отчётом при отсутствии активного head; цепочка
  предков остаётся читаемой legacy. Правка: §Миграция, §Отказы.
- F-7 — принято: распознавание face в isPlaybookNote — схемная правка п.6.
- F-8 — принято как осознанное ограничение v1 (CLI + существующий MCP add для
  сохранения предложений; обёртки face/propose — бэклог) — §Guard, «Решения для
  визы» п.5.
