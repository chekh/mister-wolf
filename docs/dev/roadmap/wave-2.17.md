# Волна 2.17 — Лица: артефакт, версии, мутация

Источник: драфт «Продуктовый роадмап 2.15+» (волна B). Кандидатный слот 2.16 из драфта сдвинут
на 2.17: 2.16 занята Инициализацией 2.0 (решение владельца
`mem_20261008_volna_2_15_konveyer_artefaktov_skill_int_c62cfc`); финальная нумерация — за
владельцем. Зависимости: B1 → B3 → B4/B5; таксономия не расползается без решения (принцип T18 —
новые статусы только уточнением существующих). Состав кандидатный до спеки волны.

## Состав (work packages волны B драфта)

- Артефакт лица — самостоятельный тип/контракт в таксономии; совместимость чтения старых лиц; base-set не пересеивается вслепую; имя типа — `face` (решено Q1); источник: драфт 2.15+ (B1), решение 393e66.
- Публичный путь создания/мутации — декларация полей (owner_skill/version) или отдельная команда версионирования лица; guard не обходится; источник: драфт 2.15+ (B2).
- Версии и история — происхождение/причина/инициатор версий сохраняются; активные задания не переключаются посередине; механика восстановления — новая версия на основе старой, линейная история, обратная supersede-ссылка исключена (решено Q1б); источник: драфт 2.15+ (B3), решения 393e66, 482ab4.
- Мутация Стюардом — шаблон записи мутации (кандидат — поля G17: причина/минимальность/границы/пример-помогает/пример-сохранить/проверка/откат); источник: драфт 2.15+ (B4), решение a5ea58.
- Owner breakglass — прямая команда аварийного отката владельца с журналом; независимость от работоспособности Стюарда; источник: драфт 2.15+ (B5), решение 482ab4.
- Сигнал «предложение» — смысловой контракт (автор/адресат/основание/предлагаемое изменение/ожидаемая польза); явная передача Стюарду; предложенное — не управляющие инструкции; техническое представление — фасет поверх существующих core-типов (решено Q2); источник: драфт 2.15+ (B6), решение 3bc98e.
- Наблюдаемость лица — список/история лиц без прямого доступа к файлам памяти; источник: драфт 2.15+ (B7).

Поглощённые темы матрицы драфта: T2 (playbook/лицо: путь создания и мутации), T8 (контур мутаций Стюарда).

## Вопросы драфта — решены (2026-10-12)

Все четыре открытых вопроса сняты решениями владельца
(`mem_20261012_resheniya_vladeltsa_po_volne_2_17_q1_q1b_164d9b`):

- Q1 — решено: имя типа артефакта лица — `face` (не playbook); миграция старых
  playbook-записей в контракт face. Снят блокер B1/B3.
- Q1б — решено: восстановление прежней версии — новая версия на основе старой
  (линейная история; обратная supersede-ссылка исключена).
- Q2 — решено: сигнал «предложение» — фасет поверх существующих core-типов (не
  отдельный тип, не тег); поля: автор/адресат/основание/предлагаемое
  изменение/ожидаемая польза.
- Q3 — решено: адресат предложения — любой, включая вышестоящих и владельца;
  предложение — только сигнал, применение через Стюарда/владельца, проверка
  авторства обязательна.
