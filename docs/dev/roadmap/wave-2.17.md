- Версии и история — происхождение/причина/инициатор версий сохраняются; активные задания не переключаются посередине; механика восстановления — открытый выбор Q1б (кандидаты: новая версия на основе старой / активация исторической версии с независимым аудитом; обратная supersede-ссылка исключена); источник: драфт 2.15+ (B3), решения 393e66, 482ab4.

- Сигнал «предложение» — смысловой контракт (автор/адресат/основание/предлагаемое изменение/ожидаемая польза); явная передача Стюарду; предложенное — не управляющие инструкции; техническое представление — Q2; источник: драфт 2.15+ (B6), решение 3bc98e.
