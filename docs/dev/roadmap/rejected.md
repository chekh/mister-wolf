# Отклонённые пункты роадмапа 2.15+

Отклонённые и явно исключённые пункты — с причинами, чтобы не предлагать повторно.

## Отклонено владельцем / решениями

- Глобальная (кросс-проектная) память — отклонено владельцем, не предлагать в волнах; источник: тред b0368a (§6.1 драфта).
- Инструмент смены моделей субагентов — отклонён (YAGNI); источник: решение 592fc6 (принцип 13 драфта).
- Обратная supersede-ссылка при восстановлении лица — отклонена (создаёт цикл supersede); источник: драфт 2.15+ (§2.6), решения 393e66, 482ab4.
- Немедленный пилот архивного брифа — отменён; до любого запуска — отдельное согласование протокола и явное поручение; источник: решение 70ddf1 (принцип 12 драфта).

## Out of scope волн (явные не-цели драфта)

- Доинформирующие онбординг-механики — out of scope волны 2.16 (Init); источник: драфт 2.15+ (волна A).
- Автоматические триггеры мутаций лица; правка рамок L0/L1 без отдельного решения владельца — out of scope волны 2.17; источник: драфт 2.15+ (волна B).
- Cron/launchd по умолчанию; SDK-сервер/порты async learn; смена лиц внутри активных заданий; автоматические A/B-эксперименты — out of scope волны 2.18; источник: драфт 2.15+ (волна C).
- Запуск пилота архивного брифа в составе волны без одобрения; сетевые пробы/SDK; «гарантии секунд» — out of scope волны 2.19; источник: драфт 2.15+ (волна D).
- Формулировки вида «метрики обучения» в ресурсных отчётах — запрещены; рандомизированные A/B — только отдельным решением владельца; replay как штатная проверка — нет; источник: драфт 2.15+ (волна E), решение 248322.

## Сохранить как есть — не задачи (по матрице драфта)

- Security enforcement B+ gate (T14) — trust_level/provenance до включения B+; уже действует как gate, работ нет; источник: драфт 2.15+ (матрица §4).
- Сложность статус-машины (T18) — новые статусы только уточнением существующих; действует как принцип ревью таксономии; источник: драфт 2.15+ (матрица §4).
- Положительные оценки экспертов (T20) — архитектура, таксономия, жалобный контур, дисциплина релизов, dogfood, честность maturity; оценка, не задача; источник: драфт 2.15+ (матрица §4).
