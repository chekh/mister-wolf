## Состав релиза (R-01..R-14, выжимка)

- R-01 — два уровня исполнения: L0 mr-wolf выполняет сам и нанимает исполнителей напрямую; промежуточного executor-lead и уровня L2 нет.
- R-02 — свежий исполнитель по умолчанию; REUSE — только по одновременным условиям и одному корректирующему возврату.
- R-03 — параллельность проектируется заранее: зависимости, области записи, точки интеграции в плане.
- R-04 — документы как основа исполнения: docs/dev/<date>-<feat>/, поток pre-requirements → requirements → design → test-plan → plan; рабочие отчёты в docs/dev не кладутся.
- R-05 — полный жизненный цикл маршрутов сохраняется (понимание → требования/design → план → реализация → независимые проверки → интеграция → выпуск → завершение).
- R-06 — доказательное ревью и экспертные консилиумы с линзами; FINDING со свойством/основанием; DONE ≠ ACCEPTED.
- R-07 — узкий редактор документов: один проход перед содержательным ревью, содержание и ID сохраняются.
- R-08 — память без изменения таксономии (thread/note/context/history/decision/lesson/complaint); лица в штатной доставке не участвуют.
- R-09 — внутренний язык TASK/RESULT/QUESTION/BLOCKED/UPDATE/FINDING/EVIDENCE; фоновые исполнители общаются с нанимателем средствами среды.
- R-10 — gitflow и поставка: worktree, baseline, права на git по авторизации, проверки привязаны к SHA.
- R-11 — постоянные имена агентов: все штатные исполнители с префиксом wolf- (wolf-researcher, wolf-architect, wolf-developer, wolf-reviewer, wolf-tester, wolf-editor, wolf-release-engineer, wolf-expert); executor-lead/worker-* не остаются активными маршрутами; префикс не навязывается пользовательским агентам.
- R-12 — роутер, скиллы и штатная доставка без обязательных плагинов wolf-router/wolf-session-start; ядро методики независимо от имён инструментов OpenCode.
- R-13 — адаптивная адресация жалоб: цель жалобы разрешается по актуальному составу агентов (включая пользовательские без wolf-префикса); scaffolding агента без зависимости от лица/плагина.
- R-14 — Стюард временно выключен из штатного роутинга: механизмы, face-история и накопленные сигналы сохранены; автоматические вызовы исключены; возврат и полномочия wolf-steward — следующий релиз.
