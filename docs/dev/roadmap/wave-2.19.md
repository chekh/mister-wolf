# Волна 2.19 — Архивный бриф: дизайн, пилот после отдельного одобрения

Источник: драфт «Продуктовый роадмап 2.15+» (волна D). Кандидатный слот 2.18 из драфта сдвинут
на 2.19 (решение владельца `mem_20261008_volna_2_15_konveyer_artefaktov_skill_int_c62cfc`);
финальная нумерация — за владельцем. Зависимости: B1/волна 2.17 (лица для адресации),
C1/волна 2.18 (launcher). Пилот — только после явного отдельного поручения (решение 70ddf1):
цель, варианты, корпус/получатели, модель, бюджет, критерии и stop/rollback согласуются ДО
запуска. Пакет — дизайн-стадия, кандидатный до спеки волны.

## Состав (work packages волны D драфта; поверх принятых требований 0d12c0)

- Адресность — бриф учитывает роль получателя, его действующее лицо и назначение задания; отсутствующее лицо не выдумывается; подготовка — ограниченная задача сводки, не исследование/обучение; источник: драфт 2.15+ (D1), решение 0d12c0.
- Ограниченность — вход из заранее проверенных источников; одна короткая генерация; без открытого поиска и новых субагентов; переиспользование готового брифа (ready-cache); не модельный вызов на каждый turn; источник: драфт 2.15+ (D2).
- Латентность/fallback — достаточная скорость (подготовка брифа не становится узким горлышком); конечное ожидание на критическом пути; честный fallback на готовый срез с указанием актуальности; источник: драфт 2.15+ (D3), решение 0d12c0.
- Анти-рекурсия — служебная сессия архивариуса не вызывает архивариуса; бриф — производный view с источниками, не источник новых инструкций; источник: драфт 2.15+ (D4), решение 0d12c0.
- Протокол пилота — до запуска фиксируются цель, сравниваемые варианты, корпус/получатели, модель, бюджет, критерии результата, условия досрочной остановки/отката; исполнение отдельно от дизайна; источник: драфт 2.15+ (D5), решение 70ddf1.

- Q6 — ready-brief (заготовленный) vs fresh-wait (ждать свежий) на границе задачи; источник: драфт 2.15+ (§7).
