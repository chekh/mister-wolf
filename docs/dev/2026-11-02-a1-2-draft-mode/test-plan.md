## 2. TDD-контракт нового теста (наблюдаемое свойство)

Свойство: **поставка содержит носитель плотности** — после sync/init базового набора в чистый проект доставленные файлы содержат ось и поведение:

- using-skills: `density` + `standard|draft` + «standard» как умолчание при отсутствии поля;
- executor-lead (рамка) и executor-lead-playbook: доставка плотности в блоке execution + приёмка по наблюдаемым действиям, не ярлыку;
- worker-implementer (рамка + playbook): исполнение назначенной плотности, существенная неопределённость → проверка/запрос L1, сам не выбирает;
- worker-researcher / worker-reviewer (рамки + плейбуки): draft сокращает объём отчёта, не coverage/вердикт/evidence;
- негативная чувствительность: без правок шаблонов тест падает (RED фиксируется на ebe1d54).

## 3. Сценарии наблюдения (fixtures, REQ-24 минимум)

`tests/fixtures/a1-2-density/scenarios.json` — пары сценариев для пилотного сравнения на разрешённой работе (не платная кампания):

- **S1 малая однозначная задача** (mechanical fix по готовому указанию): ожидание — в draft нет лишнего исследовательского L2 и повторных проверок; наблюдение — run tokens через `wolf usage import`, число попыток, время до приёмки;
- **S2 задача с существенной неопределённостью**: ожидание — в draft появляется адресная проверка или запрос L1, а не необоснованно короткий ответ; наблюдение — те же + факт возврата/расширения анализа;
- **S3 FULL/LITE в draft**: ожидание — одинаковый смысл решения при одинаковых задаче и входах; наблюдение — результат приёмки и основания в RESULT.

Протокол применения — design.md §4; результат прогона после релиза — отдельная рабочая note с метрикой, не часть этого релиза.

## 4. Ручные/фактовые проверки публикации

- npm: `npm view mister-wolf dist-tags` → `latest = 2.24.0` (первоисточник, не вывод publish).
- GitHub: `gh release view v2.24.0` → не draft, не prerelease.
- Сайт: живой curl главной/changelog → 2.24.0.
- Delivery на чистом окружении: tarball `npm pack`, изолированная установка (HOME/npm_config_prefix/PATH в одном вызове), init/upgrade → контракт доставлен, штампы `set=2.24.0`; сверка `which wolf`/`wolf --version` после установки.

## 5. Вне проверки

- Поведение живых моделей в draft: не измеряется этим релизом (пилот после выпуска); эффект не заявляется.
- Активация живых active faces: контур Стюарда после выпуска.
