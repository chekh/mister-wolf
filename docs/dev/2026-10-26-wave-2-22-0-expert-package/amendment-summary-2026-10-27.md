  утверждении не принималось.

- **Маппинг этапов B, C, D и E–I на номера версий.** Не утверждён (предложение
  `docs/dev/2026-10-27-roadmap-v4-review/04-roadmap-v4-draft.md` §11) — эта правка его не переоткрывает.
- **design.md / plan.md / test-plan.md волны** — остаются пустыми шаблонами генератора; правка требований их
  не заменяет.
- **`docs/dev/INDEX.md`** — не правился руками (генерируется `wolf sync`).
- **Проверки кода.** `npm run check` не гонялся: правка документа, релевантен только `prettier --check`
  (exit 0). Строки «Состояние на 2.21.0» перенесены из принятой инвентаризации и не перепроверялись.
