**Метод разбора.** Секция «Полные готовые исходные тексты релиза» (`WOLF-2.20.0-COMPLETE.md`, строки 405–3218) разобрана построчно: заголовок `## <путь>` + ближайший fence-открыватель → тело до закрывающего fence. Разделители тел и подзаголовки самих файлов различаются по тому, что заголовок `## <путь>` идёт непосредственно перед fence-открывателем; заголовки вида `## Выбор исполнения` (без `/` и без расширения) файлами не считаются. Учтены оба вида fence — ``(4 обратные кавычки) и` (3).

**Нормализация при сравнении.** sha256 считается по тексту с унифицированными переводами строк (CRLF→LF), срезанными хвостовыми пробелами в строках и хвостовыми пустыми строками. Дополнительно выполнялось «мягкое» сравнение (trim каждой строки + схлопывание пустых строк; для JSON — канонический разбор с сортировкой ключей) для отделения различий форматирования от содержательных. **Результат: ни одного файла с различием только в форматировании не найдено** — все 38 расхождений содержательные.

**Границы payload.** `SOURCE-COVERAGE.json` (строки 3219–3633) — манифест покрытия, а не исходный текст; из состава payload исключён, учтён отдельно в п. 7.

## 9. Ограничения и риски

1. **Ни одного идентичного файла.** Все 38 существующих канонических/управляемых файлов переписаны целиком. Автоматическая замена по diff неприменима; требуется решение по каждому файлу (замена / частичное / отклонение). Это содержательный вывод инвентаризации, а не дефект скрипта.
2. **Сжатие vs. расширение одновременно.** payload одновременно короче (например, `mr-wolf.md` 36 против 140 строк) и семантически богаче (новые роли `wolf-protocol`, `wolf-workplan`, `steward-language`, `task-state`). Простое «применить пакет» уменьшит объём канона — риск потери требований, не зафиксированных в payload. Сопоставление по sha256 этого не показывает.
3. **13 новых файлов вне манифеста покрытия** (п. 8.3) — для них нет ни действия миграции, ни указания на целевой путь установки.
4. **Runtime вне payload.** `templates/opencode/plugins/*` и `.opencode/plugins/*` в payload отсутствуют; манифест отправляет их в `specs/RUNTIME-AND-MIGRATION.md` — спецификации, которой в пакете нет. `evals/`, `schemas/`, `templates/base/language/` также требуют runtime (пины языка, task-state, complaint inbox), заявленного в `RELEASE-TASK.md`, но не реализованного.
5. **Пути `schemas/` и `evals/`** — в 2.21.0 таких каталогов в корне репозитория нет; сравнение с базой невозможно (verdict «новый» по отсутствию файла, а не по расхождению текста).
