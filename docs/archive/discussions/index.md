## Как пользоваться

- Новые дискуссии добавлять с говорящими именами: `YYYY-MM-DD-<тема>.md`
- Пустые плейсхолдеры либо заполнять, либо удалять — не оставлять висячими
- Каждый файл должен начинаться с `# Тема` и краткого описания о чём речь
