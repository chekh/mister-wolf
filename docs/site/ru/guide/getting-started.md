# Начните с первой полезной задачи

Полная организация сейчас ориентирована на OpenCode. Этот путь подключает Wolf к существующему проекту, знакомит с документами и запускает задачу обычным поручением. Дополнительный режим только памяти описан ниже.

## Требования

- Node.js 22 или 24, macOS либо Linux с glibc.
- Установленный OpenCode и рабочая настройка модели/провайдера для полной организации.
- Alpine/musl в этой поставке не поддерживается; Windows — best-effort.

## Установите и подключите

Выполните в проекте, над которым будет работать Wolf:

```bash
npm install -g mister-wolf
cd my-project
wolf init --full --platform opencode
wolf bootstrap
```

Имя пакета — именно **`mister-wolf`**. `mr-wolf` — другой пакет npm.

`init --full` записывает поставляемые рамки агентов, скиллы, команды и плагины, создаёт недостающие стартовые лица и настраивает MCP-сервер Wolf в `opencode.json`. Агентом по умолчанию становится `mr-wolf`. Существующие файлы и локальные изменения обрабатываются по [правилам инициализации/обновления](/ru/guide/upgrade); для живого проекта могут понадобиться решения.

**Перезапустите OpenCode**, чтобы загрузился проектный конфиг. Без явного переопределения модели используются настройки платформы; инициализация не выбирает за вас провайдера.

## Познакомьте с проектом

`bootstrap` сканирует файлы, регистрирует ссылки на документы, предлагает начальные конвенции и открывает тред знакомства. Команда подготавливает сведения, но не запускает LLM и не завершает знакомство самостоятельно.

В OpenCode обратитесь к Wolf:

> Разбери со мной результаты bootstrap. Подтверди назначение проекта, канонические документы и обязательные проверки; спроси о существенных пробелах и помоги завершить знакомство с проектом.

Ожидаемый результат — понятная сводка конвенций, внесённых уточнений и открытых вопросов. Изучать типы памяти не требуется. [Bootstrap](/ru/guide/bootstrap) объясняет проверку и повторные запуски.

## Дайте первое поручение

Например:

> Подготовь краткое руководство для нового участника. Используй существующие документы проекта, включи запуск и первую полезную задачу, по возможности безопасно проверь команды. Спроси меня, если недостающее решение влияет на результат.

Это пример поручения, а не запись выполненного прогона. Методики предписывают Wolf уточнить намерение и критерии приёмки, поручить L1 организацию ограниченных задач L2, интегрировать выводы и представить результат. Вы должны получить руководство или путь к нему, сведения о выполненной проверке, ограничения и решения, которые ещё нужны от вас. Фактическое поведение зависит от модели, харнеса и полномочий в проекте.

Для продолжения позже попросите Wolf сохранить существенное состояние, а в следующей сессии назовите задачу. См. [Работа с Wolf](/ru/guide/working-with-wolf).

## Если чего-то не хватает

- Нет агента `mr-wolf` или MCP-инструментов: проверьте `--full --platform opencode`, затем перезапустите OpenCode. Обычный `wolf init` намеренно устанавливает меньше.
- Ошибки модели/провайдера: проверьте настройки OpenCode; Wolf не предоставляет доступ к моделям.
- Ошибки целостности: выполните `wolf doctor`, прочитайте конкретное замечание и используйте [устранение неполадок](/ru/guide/troubleshooting). Успешный doctor проверяет целостность, а не завершение задачи.
- Неясная конвенция проекта: обсудите её с Wolf, прежде чем считать предложенное правило действующим.

## Дополнительно: память без полной организации

```bash
npm install -g mister-wolf
cd my-project
wolf init
wolf bootstrap
```

Обычный `init` создаёт скелет памяти и onboarding-блок в `AGENTS.md`; полный набор агентов и платформенный MCP-конфиг не записывает. Подключите совместимого помощника через [MCP](/ru/guide/mcp) или просматривайте состояние CLI-командами, например `wolf brief` и `wolf search`.

`npx mister-wolf init` — пробный режим: скелет памяти без полного набора и MCP-конфигов. Опциональные конфиги (`--platform opencode,claude`) не доказывают равенство полной организации на двух платформах. См. [Возможности](/ru/guide/capabilities).

## Обновляйте при необходимости

```bash
wolf upgrade --check
wolf upgrade
```

Изучите локальные отличия и защиту перед выбором исхода обновления. [Руководство по обновлению](/ru/guide/upgrade) описывает весь процесс. Устройство памяти доступно в [Модели памяти](/ru/guide/memory), когда потребуется проверка или настройка.
