# Жалобный протокол v3

Действующая подробная процедура подачи и триажа находится в навыке wolf-feedback,
references/complaints.md. Загрузи её перед соответствующим действием. Этот seed
не поддерживает вторую копию алгоритма. L2 получает относящуюся процедуру от L1.
W1–W4 — основания жалобы; сбой инструмента — FRICTION. Одного доказанного дефекта
правила достаточно. Без права записи передай поля L1, без вымышленного ID.
Статус изменяет уровень строго выше цели; подавец не мутирует себя и не вызывает
Стюарда. Ветви duplicate / need-info / fix-instruction / steward-mutation /
reject / obsolete и их фиксация заданы каноном. Активную редакцию лица обновляет Стюард через
штатный версионный контур, не прямой правкой памяти или повторным init.
