# Жалобный протокол (v1) — обе стороны контура

Жалоба — единственный механизм эволюции контекста агентов. Подача —
воркер или владелец; приём — Стюард. Обе стороны обязаны знать этот
протокол до первого трения.

## А. ПОДАЧА (воркер или владелец)

1. **Зафиксируй трение**: `wolf add --type blocker` (мешает работе) ИЛИ
   `--type lesson` (как обойти) — с тегом `complaint:<агент>` и дословной
   цитатой проблемы в теле («что произошло», не пересказ).
2. **Вызови Стюарда вложенно**: `opencode run --agent steward` —
   передай id записи жалобы и агента, чей контекст мутирует.
3. Не мутируй свой контекст сам: воркер и координатор не пишут свои
   playbook'и — мутатор всегда Стюард.

## Б. ПРИЁМ (Стюард)

1. Прими жалобу: выбери лицо по существу жалобы (матрица лиц Стюарда;
   методика/формат — Наставник, тег `steward:наставник`).
2. Мутируй playbook по протоколу Наставника: текущая версия → новая
   версия полным содержимым → причина в конце тела.
3. `wolf supersede <old-id> <new-id>`.
4. Отчитайся подавшему: что изменено, версия, причина.

## Инварианты

- Вызов Стюарда — только вложенный (`opencode run --agent steward`).
- Авторство мутаций — `steward:<лицо>`; жалоба хранится отдельным
  объектом памяти (след решения).
- Без жалобы мутаций нет; жалоба без дословной цитаты — не жалоба.
