## Находки для спеки/платформы

1. Субагенты недоступны через `opencode run` напрямую — нужен `mode: all` в рамке (ограничение платформы)
2. Скилл-контаминация (см. выше) → правило описаний скиллов
3. Actor-атрибуция мутаций (`--created-by`) — обязательна
4. Дублирование протокола skill+playbook у A — чистка (скилл = рамка без дублирующего протокола)
5. `opencode run --format json` — рабочий источник метрик (step_finish.tokens); cost=0 у локальных моделей — weighted-формула вместо $
6. A2 лишний `mr-wolf_add` (отчёт в память без нужды) — дисциплина записи
